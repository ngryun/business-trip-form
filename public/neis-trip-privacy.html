강원 NEIS 여비정산 도우미 (비공식) · 버전 0.2.0

1. 기능과 처리 목적

이 확장 프로그램은 사용자가 로그인한 강원 NEIS 개인출장관리에서 체크한 출장 한 건을 읽고, 사용자가 확인한 기본 정보를 여비정산신청서 웹앱에 채우는 도구입니다. 교육부·교육청·한국교육학술정보원(KERIS)의 공식 제품이 아니며, 이들 기관의 승인이나 제휴를 나타내지 않습니다.

2. 읽는 정보

사용자가 팝업의 동의 및 읽기 버튼을 누르면 상단의 성명·소속·직급, 체크한 행의 순번·출장지·출장기간·출장목적·결재상태·출장종류·공용차량 이용 여부·삭제 여부를 읽습니다. 현재 탭 주소는 지원하는 NEIS 페이지인지 확인하기 위해 사용합니다. 로그인 비밀번호·인증서·인증 쿠키·학생 자료·전체 방문 기록에는 접근하지 않습니다.

3. 전달 대상과 방법

확인 후 ‘여비정산에 채우기’를 누르면 성명·소속·직급·출장지·시작/종료 일시와 여기에서 계산한 이동 날짜·제출 날짜를 https://ngryun.github.io/business-trip-form/의 여비정산 웹앱에 전달합니다. 사용자가 설정한 경우 동일 컴퓨터의 localhost 개발 서버로 전달할 수 있습니다. 출장목적 등 확인용 정보는 정산 앱으로 전달하지 않습니다.

값은 URL 프래그먼트(# 뒤)에 담겨 대상 페이지의 JavaScript에서 처리됩니다. 프래그먼트는 일반 HTTP 요청에 포함되지 않지만 브라우저 주소·기록에 남을 수 있고 대상 페이지에서는 읽을 수 있습니다. 별도의 수집 서버, 분석 서비스, 광고 서비스로 출장 정보를 전송하는 기능은 없습니다.

여비정산 웹페이지는 GitHub Pages에서 제공됩니다. 페이지를 여는 일반 접속 과정에서 호스팅 제공자는 IP 주소 등 접속 정보를 처리할 수 있습니다. 이는 URL 프래그먼트로 전달한 출장 입력값과는 다릅니다. 호스팅 제공자의 처리는 GitHub 개인정보처리방침을 참고하세요.

4. 저장 기간과 삭제

확장 프로그램은 읽은 값과 수정한 값을 팝업이 열려 있는 동안 메모리에서만 유지하며, 팝업을 닫으면 유지하지 않습니다. 확장 프로그램 자체의 영구 저장소는 사용하지 않습니다.

연결된 여비정산 앱은 입력값을 해당 사이트의 브라우저 localStorage에 임시 저장하며, 초기화 또는 사이트 데이터 삭제 전까지 남을 수 있습니다. 정산 앱의 ‘초기화’로 입력값을 지우고, 별도로 저장한 신청자 목록·서명은 각각의 삭제 기능을 사용하세요. 사이트에 저장된 데이터를 모두 지우려면 Chrome 설정에서 해당 사이트의 데이터를 삭제할 수 있습니다. 브라우저 기록과 다운로드한 문서는 별도로 삭제해야 합니다. 개발자는 사용자의 기기 안에 저장된 값을 원격으로 삭제할 수 없습니다.

5. 권한과 보안

activeTab은 사용자가 확장을 실행한 현재 탭에 일시적으로 접근하기 위해, scripting은 패키지에 포함된 읽기 전용 스크립트를 실행하기 위해 사용합니다. 백그라운드 상시 수집, NEIS 신청·승인·수정·삭제, 원격 코드 다운로드 및 실행 기능은 없습니다. 정산 연결은 지정된 HTTPS 앱 또는 동일 컴퓨터의 개발 서버로 제한합니다.

6. 이용 제한

처리한 정보는 사용자가 요청한 출장 정보 확인 및 정산 양식 작성 목적으로만 사용합니다. 판매, 광고, 대출·신용 평가 또는 해당 기능과 무관한 제삼자 제공에 사용하지 않습니다. 개발자는 사용자의 출장 정보를 수집 서버에서 보관하거나 열람하지 않습니다. 이 확장 프로그램의 사용자 데이터 이용은 Chrome 웹 스토어 사용자 데이터 정책의 Limited Use 제한을 준수합니다.

7. 문의와 변경

문의 시에도 실제 출장 내용이나 인증 정보를 보내지 마세요. 개인정보 처리 방식이 변경되면 이 문서와 필요한 앱 내 안내를 갱신합니다. 문의 주소는 문서 상단에 표시합니다.
